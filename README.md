# graphic-drive-sync

ระบบจัดการ Google Sheets & Google Drive Automation สำหรับทีมกราฟิก
- Frontend & Backend: Next.js (App Router)
- Styling: Tailwind CSS & shadcn/ui
- Validation & Forms: Zod + React Hook Form
- API & Data Layer: Google Apps Script Web App (Connected to Google Sheets & Drive)
- Deployment: Vercel
